## 6. How to Run

1. Open the required tutorial folder.
2. Open the Terminal in that folder.
3. Compile the Java files:

```bash
javac *.java
```

4. Run the main Java class. For example:

```bash
java Main
```

**Notes:**
- Some tutorials use a different main class name, such as `HelloWorld`.
- Tutorial 6 uses `task.txt` to save and load tasks.
- Tutorial 7 uses Java Swing GUI and requires a desktop environment that supports graphical applications.
- The GUI application may not run directly in GitHub Codespaces because it does not provide a graphical display by default.
